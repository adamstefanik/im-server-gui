Instant Message Server - Help & Protocol

Overview

This application implements the Bonus Task: GUI for Instant Message Server, integrating a modern Web GUI with full backward-compatibility for TCP Telnet clients from Task 4.

Command Reference (Task 4 Protocol)

Command Description
#setMyName <name> Changes your nickname. Name must be without spaces and unique.
#join <room> Joins or creates a discussion room.
#leave <room> Leaves a discussion room.
#groups Lists all rooms you are currently in.
#sendPrivate <user> <msg> Sends a private direct message to the specified user.
any plain text Broadcasts message to all clients sharing at least one room with you.

Cross-Platform Interoperability

Clients can connect both through this Web browser and via TCP Telnet (telnet localhost 33000). Messages and private chats are routed transparently between both client types!
